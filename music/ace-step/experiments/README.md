# Expériences ACE-Step

Essais, variantes, comparaisons, résultats et observations issues des expérimentations.

## Données à conserver

Pour chaque expérience utile, conserver autant que possible :

- version d’ACE-Step et modèle utilisés ;
- mode de génération ;
- paramètres réellement présents dans l’interface locale ;
- seed et état du seed aléatoire ;
- BPM, tonalité, mesure et durée ;
- batch size ;
- paramètres DiT et LM pertinents ;
- caption et lyrics ;
- temps de génération ;
- résultat obtenu et observations d’écoute ;
- limites ou anomalies constatées.

Les temps de génération et contraintes matérielles font partie des observations expérimentales lorsqu’ils influencent le protocole. Les réglages vus dans notre interface locale priment pour nos expériences ; une information provenant d’une autre interface ou d’une autre version doit être explicitement distinguée.
