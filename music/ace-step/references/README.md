# Références ACE-Step

Références externes, liens vers les sources officielles et ressources particulièrement utiles.

## Sources officielles

- **Dépôt officiel ACE-Step 1.5** — https://github.com/ace-step/ACE-Step-1.5
  Source principale pour le code, les releases et les évolutions du projet.

- **Documentation officielle ACE-Step 1.5** — https://ace-step.github.io/ACE-Step-1.5/en/
  Documentation générale du fonctionnement et des fonctionnalités.

- **Guide de l'interface Gradio** — https://ace-step.github.io/ACE-Step-1.5/en/GRADIO_GUIDE
  Référence pour l'interface utilisée pour nos générations locales.

- **Guide musicien / création** — https://ace-step.github.io/ACE-Step-1.5/en/ace_step_musicians_guide
  Référence pratique pour les usages musicaux, les paroles, les captions et le workflow de création.

- **Documentation d'inférence** — https://github.com/ACE-Step/ACE-Step-1.5/blob/main/docs/en/INFERENCE.md
  Référence technique pour les paramètres et méthodes d'inférence.

- **Documentation UI / support** — https://github.com/ACE-Step/ACE-Step-1.5/blob/main/docs/en/UI_SUPPORT.md
  Informations liées aux interfaces et à leur prise en charge.

- **Releases officielles** — https://github.com/ace-step/ACE-Step-1.5/releases
  À consulter pour vérifier les versions, changements et éventuelles incompatibilités.

## Règle d'utilisation

Pour tout comportement susceptible d'évoluer avec une nouvelle version d'ACE-Step, vérifier d'abord la documentation et les releases officielles actuelles.

Les retours communautaires (GitHub Issues, Hugging Face, Reddit, etc.) peuvent compléter ces sources pour identifier des techniques ou problèmes réels, mais doivent être distingués des informations officielles.

Ne pas recopier ici la documentation complète. Ce fichier sert de point d'entrée vers les sources et de mémoire de notre connaissance opérationnelle.
