# ACE-Step — Création musicale

Espace dédié à la création, l’expérimentation et la documentation autour d’ACE-Step.

## Arborescence

- `presets/` — presets de génération validés et réutilisables.
- `workflows/` — méthodes de travail et procédures testées.
- `experiments/` — essais, variantes et journaux d’expérimentation.
- `references/` — liens et références externes, notamment vers la documentation officielle et le dépôt ACE-Step.

## Règles opérationnelles

- Les informations susceptibles d’évoluer avec les versions d’ACE-Step doivent rester référencées vers les sources officielles plutôt que recopiées inutilement ici.
- Notre axe vocal actuel est **voix féminine uniquement**, y compris lorsque les paroles sont écrites depuis un point de vue masculin. Les voix masculines seront étudiées plus tard comme variantes expérimentales séparées.
- L’interface locale réellement utilisée est la référence pratique pour les paramètres disponibles. Ne pas supposer qu’un réglage visible dans une autre interface ou dans une documentation ancienne existe dans notre installation.
- Pour les premières expérimentations, privilégier des extraits courts et un batch réduit lorsque le temps de génération rend l’exploration complète trop coûteuse.
- Documenter les temps de génération réels lorsque ceux-ci influencent le protocole expérimental.

Les réglages et comportements susceptibles de varier selon la version, le modèle ou le matériel doivent être enregistrés avec leur contexte plutôt que présentés comme universels.
