# ACE-Step — Création musicale

Espace dédié à la création, l’expérimentation et la documentation autour d’ACE-Step.

## Arborescence

- `presets/` — presets de génération validés et réutilisables.
- `workflows/` — méthodes de travail et procédures testées.
- `experiments/` — essais, variantes et journaux d’expérimentation.
- `references/` — liens et références externes, notamment vers la documentation officielle et le dépôt ACE-Step.

Les informations susceptibles d’évoluer avec les versions d’ACE-Step doivent rester référencées vers les sources officielles plutôt que recopiées inutilement ici.
