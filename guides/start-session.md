# Guide — Démarrer une session Codex CORE

1. Lire `AGENTS.md` du dépôt courant.
2. Lire `memory/current-state.md`.
3. Lire `context/repos.md`.
4. Vérifier les remotes et branches :

```bash
git remote -v
git status --short --branch
```

5. Si la mission touche un autre repo, lire son `AGENTS.md` et/ou `CLAUDE.md` avant toute action.
6. Si un repo privé doit être pull/cloné, vérifier qu'un token est disponible sans afficher sa valeur.
7. Faire un plan avant toute écriture.
